# Часть 3. Многопоточная и многопроцессорная обработка

## Архитектура

Producer-Consumer паттерн:
1. **Producer** (поток) — сканирует файлы → `file_q`
2. **Consumers** (потоки) — читают файлы → `data_q`
3. **Aug-workers** (процессы) — аугментация → `result_q`

## Компоненты

- `augment.py` — аугментация (повороты, отражения, шум)
- `producer_consumer.py` — пайплайн с потоками и процессами
- `performance.py` — сравнение производительности

## Запуск

```bash
python run_pipeline.py
